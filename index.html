Headphone setup & playing tips

Connect your interface to your Mac by USB, plug headphones into the interface, and select it in Mac Sound settings for output. Start listening and allow audio input, then select your guitar interface above. Your interface monitors your guitar directly. Only the band plays back through the page.

On the Tone Master Pro use Standard Recording and assign USB playback 1/2 to headphones. Choose input 3 if available. On THR30II use Record Dry and choose input 2. If Chrome offers only processed input on the TMP, try a clean preset. Test each meter by picking and muting a note with delay on. The dry signal stops when the string does.

Let an open major or minor chord ring, play three distinct single notes, then pause for a reply. Keep this tab visible. The demo runs a synthesized guitar through the same listener. All audio processing happens on your device.
